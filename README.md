The most honest status page message an AI agent writes while every server is down: one plain, first-person line naming what is broken, admitting what it does not know yet, and promising the next update — no invented cause, no fake ETA.

The entry line (156 characters):

> Checkout is down since 14:02 UTC and I don't know why yet. Your carts and orders are safe. I'll update this page every 15 minutes until payments work again.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (falling back to `./output/entry.txt` if `/output` is not writable) and exits 0.
